Every file is measured with EBU R128 — the loudness scale (LUFS) that streaming services and broadcasters work with.

The exact gain is written into the audio itself. Lossless files stay lossless, lossy ones are re-encoded at the highest quality.

Features

Small app, done properly.

Pick your target

Streaming (−14), ReplayGain (−18), Broadcast/Film (−23) or any custom LUFS value.

Album mode

Drop a folder and it gets one shared gain — the quiet intro stays quiet, the drop stays big.

Lossless stays lossless

FLAC, WAV, AIFF, APE and WavPack are re-encoded without any quality loss.

Safe by default

Originals are copied to an “Ohmega Backup” folder first. One checkbox if you don't want it.

Batch & profiles

Hundreds of files and whole folder trees at once. Save your favourite settings as a profile.

Native everywhere

Qt 6 on any Linux desktop, SwiftUI on macOS, a native app on Windows — same engine, same results. A command-line tool comes with it.

Command line

Same engine, in your terminal.

ohmega-cli only needs Python and ffmpeg. Folders are scanned recursively and originals are backed up before any change.

Normalize to the default Streaming target (−14 LUFS)
ohmega-cli track1.flac track2.mp3
Pick a target — streaming · replaygain · broadcast
ohmega-cli -t broadcast ~/Music
Treat a folder as one album, with a shared gain
ohmega-cli --album ~/Music/Album
Preview the gain without changing anything
ohmega-cli --dry-run ~/Music

Inside the Flatpak: flatpak run --command=ohmega-cli io.github.Daniel_v8.Ohmega --help · from the .zip: python3 cli.py --help

How is this different from ReplayGain?

ReplayGain only adds a tag, and the player has to read it and turn the volume down. Many players, cars and phones ignore it. Ohmega changes the audio itself, so the result works everywhere.

Will it damage my files?

Lossless formats keep every bit of quality. Lossy files are re-encoded once at the highest quality, which is inaudible in practice. Either way, originals are backed up first unless you turn that off.

Which target should I pick?

−14 LUFS (Streaming) matches Spotify and YouTube and is the best choice for a music library. −18 LUFS leaves more headroom for dynamic music, −23 LUFS is the broadcast and film standard.
